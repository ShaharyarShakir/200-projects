# Setting Up Golang with React

Modern web applications often need a fast backend and a responsive frontend. Combining Golang (Go) with React creates a powerful full-stack setup that is fast, scalable, and developer-friendly.

In this guide, you’ll learn how to:

- Set up a Golang backend
- Create a React frontend
- Connect both applications together
- Handle API requests
- Run everything locally

By the end, you’ll have a working full-stack application powered by Go and React.

## Step 1: Create the Golang Backend

### Initialize the Backend

Create a backend folder:

```bash
mkdir backend
cd backend
```

Initialize a Go module:

```bash
go mod init fullstack-app
```

Install the router package:

```bash
go get github.com/gorilla/mux
```

---

### Create `main.go`

```go
package main

import (
	"encoding/json"
	"log"
	"net/http"

	"github.com/gorilla/mux"
)

type Message struct {
	Text string `json:"text"`
}

func homeHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")

	message := Message{
		Text: "Hello from Golang backend!",
	}

	json.NewEncoder(w).Encode(message)
}

func main() {
	r := mux.NewRouter()

	r.HandleFunc("/api/message", homeHandler).Methods("GET")

	log.Println("Server running on port 8080")
	http.ListenAndServe(":8080", r)
}
```

---

### Run the Backend

Start the Go server:

```bash
go run main.go
```

You should see:

```bash
Server running on port 8080
```

Visit:

```txt
http://localhost:8080/api/message
```

Response:

```json
{
  "text": "Hello from Golang backend!"
}
```

## Step 3: Connect React to Golang

Now let’s fetch data from the Go API.

Open:

```txt
frontend/src/App.js
```

Replace the content with:

```jsx
import { useEffect, useState } from "react";

function App() {
  const [message, setMessage] = useState("");

  useEffect(() => {
    fetch("http://localhost:8080/api/message")
      .then((res) => res.json())
      .then((data) => setMessage(data.text))
      .catch((err) => console.error(err));
  }, []);

  return (
    <div style={{ padding: "40px" }}>
      <h1>React + Golang</h1>
      <p>{message}</p>
    </div>
  );
}

export default App;
```

## Step 4: Fix CORS Issues

Since React and Go run on different ports, you may encounter CORS errors.

Install the CORS middleware:

```bash
go get github.com/rs/cors
```

Update `main.go`:

```go
package main

import (
	"encoding/json"
	"log"
	"net/http"

	"github.com/gorilla/mux"
	"github.com/rs/cors"
)

type Message struct {
	Text string `json:"text"`
}

func homeHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")

	message := Message{
		Text: "Hello from Golang backend!",
	}

	json.NewEncoder(w).Encode(message)
}

func main() {
	r := mux.NewRouter()

	r.HandleFunc("/api/message", homeHandler).Methods("GET")

	c := cors.New(cors.Options{
		AllowedOrigins: []string{"http://localhost:3000"},
		AllowedMethods: []string{"GET", "POST", "PUT", "DELETE"},
	})

	handler := c.Handler(r)

	log.Println("Server running on port 8080")
	http.ListenAndServe(":8080", handler)
}
```

Restart the backend server.

Now React should successfully communicate with Go.

## Step 5: Build for Production

When your application is ready for deployment, build the React app:

```bash
npm run build
```

This creates a production-ready `build/` folder.

You can serve these static files directly from Go.

## Step 6: Serve React with Golang

Update `main.go`:

```go
package main

import (
	"net/http"
)

func main() {
	fs := http.FileServer(http.Dir("./frontend/build"))

	http.Handle("/", fs)

	http.ListenAndServe(":8080", nil)
}
```

Now Go serves both:

- Backend APIs
- React frontend

This simplifies deployment significantly.

## Common Problems and Solutions

### Port Already in Use

Change the port in either React or Go.

Example:

```go
http.ListenAndServe(":5000", handler)
```

---

### CORS Errors

Make sure:

- Backend allows frontend origin
- Correct ports are configured
- Middleware is properly applied

---

### API Not Fetching

Check:

- Backend server is running
- Endpoint URL is correct
- Browser console for errors
